**Holix Play** is a native client for your own [Jellyfin](https://jellyfin.org) server — built for the big screen first.

- **Plays it properly** — Dolby Vision and HDR, direct play and server remux, intro skip, trickplay, chapters.
- **Profiles for the whole household** — Netflix-style sub-profiles with optional PIN locks, kids profiles and a guest mode.
- **Ambilight without a box** — the player extracts edge colours itself and drives Philips Hue, Govee, WLED, Hyperion/HyperHDR, Nanoleaf, LIFX and more. No HDMI sync box needed.
- **Smart home** — Home Assistant integration, Apple Home scenes, Siri and Shortcuts.
- **Apple Watch remote**, screensaver with your photos, Trakt scrobbling.

The apps are coming soon to the App Store and Google Play.

### Open-source components

| Repository | What it is |
|---|---|
| [holix-homeassistant](https://github.com/HolixPlay/holix-homeassistant) | Home Assistant integration (HACS) — media player, profiles, ambilight, automation triggers |
| [jellyfin-plugin-holix](https://github.com/HolixPlay/jellyfin-plugin-holix) | Jellyfin server plugin — household profiles, PIN locks, signed profile sessions |
